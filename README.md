# ABC 英语小游戏

给中国小朋友学英语单词的网页小游戏：看图、听声音、点一点，再配上“间隔复习”（按遗忘规律，在合适的时间让孩子再见到这个词），让单词记得更牢。纯静态网页，手机浏览器、微信里直接打开，不用安装。

在线地址：<https://alexlee-xz.github.io/abc_game/>

## 快速开始

1. 手机（微信或浏览器）打开上面的链接，**打开手机声音**。
2. 第一次打开会问**小朋友叫什么名字**，输入后点“开始学习”。学习记录按名字自动保存，不用手动备份。
3. 点首页的 **“今日魔法任务”**，陪孩子玩一组，几分钟就够。
4. 每天玩一次就好。
5. 偶尔点首页最下面的 **“家长页”**，看看孩子的进度，或复制“每周小结”发到微信。

建议把页面加到手机桌面或微信“收藏”，方便每天打开。

## 孩子怎么玩

首页有这几个入口：

- **今日魔法任务**：每天的主线。先认识几个新词，再“听一听，找一找”（听声音，从几张图里点对的那张）。到期该复习的旧词会自动混进来。做完后还可以点“再练一组”。
  - 词越熟，题越难：新词和刚学的词是 3 选 1、只听单词；长到 🌿 以后变成 4 选 1，干扰图会故意放容易混的（比如医生和护士）；长到 🪴 以后，“I can be a…”系列的词改成听整句找图。
  - 点错了不用着急：第一次点错会再读一遍；连点错 2 次，正确的图会亮起来并带着读。答错的词隔几题后会“再来一次”，这次只算练习。
  - 做完任务的页面会列出“家长小任务”：今天新学的词、答错过的词，附一句生活里怎么用（比如“看到消防车时说 Fire station!”）。
  - **英语为主，中文少说**：中文翻译只在“认识新朋友”页播；答题时只听英文，中文提示“听一听，找一找”只在每组前 2 题出现。想要以前那种每题都带中文的方式，家长页里可以改。
  - **换个人说**：复习题会随机用另一个英文声音（男声）读同一个词，让孩子认的是“这个词”而不是“这个声音”。新词一直用第一个声音。
  - **说一说**（偶尔出现）：挑一个已经很熟的词（🌳 以上），只给图、不播声音，让孩子用英语说出来，由家长点“说对了”或“没说出来”。说对算一次复习答对；没说出来不扣分，会带孩子读两遍，稍后补考一道选择题。
  - **动一动**（任务最后）：播一句英语指令，比如 “Show me a dancer!”“Slide down the pole!”，让孩子做动作，家长点“做完啦”。不计分。
- **听故事，排顺序**：学会一个单元的词后在首页解锁。先播一遍由几句话组成的小故事（比如“警报铃响了 → 我们到达大楼 → 火被扑熄了”），孩子把图片按故事的顺序一张一张点出来。点错会把整个故事再播一遍，不直接告诉答案。这一项不影响复习日程，家长页会记完成次数。
- **我的小花园**：每个词是一颗种子，答对越多越长大：🌰 → 🌱 → 🌿 → 🪴 → 🌳 → 🍎。头上有 💧 的小树“渴了”，表示该复习了。
- **单元练习**：按主题自由学。
  - 学一学：点图片听英文和中文；每个词下面有音标，点“跟读”让孩子读一读。录多久可以在家长页分别设置“单词”和“句子”的录音时长（见下）。
  - 玩一玩：听声音，找图片。

所有声音都是提前合成好的 mp3（英文用美式儿童感女声和美式男声，中文用普通话女声），微信里也能正常播放。

**图片**：所有词和句子的配图都是统一风格的原创简笔画（粗深棕色轮廓 + 平涂色块，内联 SVG，源码在 [js/content/art.js](js/content/art.js)）。人物共用同一个“大头小朋友”模板，只靠服装和道具区分职业，不靠性别；因为是矢量图，在任何手机上长得一样（emoji 在不同系统里差别很大）。想看全部图片，打开 [tools/art_preview.html](tools/art_preview.html)（本地起一个静态服务器即可）。换图只需改 art.js 里对应 id 的那一段，找不到图时会自动用回原来的 emoji。

## 复习是怎么安排的

- 学会一个词后，会在第 **1、2、4、7、15、30** 天各再考一次，之后每 15 天一次。
- 新词当天要**连续 2 次“第一次就点对，而且不犹豫”**才算学会、小树才长大。猜对的、想了很久才点对的（听完题目后超过 9 秒），都不算学会。
- 点错了：小树降一级，明天再练。
- “再练一组”、不够题时补的“巩固题”，以及答错后的“再来一次”，都只是多练，不影响复习日程，也不影响统计。“动一动”和“听故事排顺序”也不影响。
- “说一说”说对了按复习答对算；没说出来不算遗忘，由稍后补考的那道选择题决定升级还是降级。
- 每组魔法任务至少 10 题。

## 家长页怎么看、怎么调

首页最下面点“家长页”，里面有：

| 栏目 | 看什么 / 能做什么 |
|---|---|
| 今天、学习进度、未来 7 天 | 今天任务做完没有、有几个词该复习、各成长阶段的词数、接下来几天要复习多少 |
| **今日家长小任务** | 今天新学的词和答错过的词，每个词附一句“在生活里怎么用”。孩子在现实中用一用，比多做几道题记得更牢 |
| 遗忘情况 | “隔天复习测试”做了几次，其中第一次就点错（遗忘）几次、占多少。**只有“以前学会过、隔了至少一天、第一次就点错”才算遗忘**，新词点错只算“还没学会”。测试不到 10 次时仅供参考 |
| **遗忘曲线** | 一张折线图：横轴是“隔了几天再测”，纵轴是“第一次就点对的比例”，点下面的 n 是测试次数。曲线掉得越慢，说明记得越牢。空心点表示测试少于 3 次，别当真；虚线是 80% 的参考线。要隔天复习的词多了才会有点，一开始是空的 |
| 最容易忘的词 / 还没学会的词 | 需要多陪孩子练的词 |
| **学习方式** | 三组开关：**中文翻译**（“只在新词页”默认，英语输入更多；“总是播放”适合刚接触英语的孩子）、**说一说**（开/关）、**动一动**（开/关）。孩子不愿意开口或者环境不方便时，可以先关掉说一说和动一动 |
| **每天新词数** | 滑块，1–20，默认 3。每个新词会先教一遍、当天再考 2 次。孩子觉得太简单就调大；注意力不够就调小 |
| **语速** | 两个滑块，范围 ×0.5–×2.0，默认 ×1.0（原速）。“提示语速”管中文提示和夸奖，“英语播放语速”管英文单词和句子，旁边有“试听”按钮。超出 ×0.7–×1.5 时声音可能有点变调；个别手机浏览器不支持变速，听着没变化时请改用系统浏览器打开 |
| **跟读录音时长** | “单词”和“句子”各有一组“最短 / 最长”滑块，单位秒。单词默认 3～6 秒（可调 1～10），句子默认 4～10 秒（可调 2～20）。先前的固定录音是 3 秒。“最长”是自动停止的时间；“最短”是录满这么久后，孩子才能点“✋ 说完了”提前结束。最短拉到超过最长时，最长会跟着调。有语音识别的浏览器（如 iPhone Safari）说完就会自动结束，只用到“最长”；只能录音回放的浏览器（如微信）两个值都用。设置按小朋友分开保存 |
| 最近 30 天打卡 | 每天有没有完成魔法任务 |
| **每周小结** | 最近 7 天的打卡天数、新认识的词、小花园进展、一次就对的正确率、容易错的词、生活里怎么用，再加一两条建议。点“复制，发到微信”，打开微信粘贴即可（家人、老师都行）。正确率和“容易错”来自逐题记录（最近 400 题），每天玩得很多时只统计得到最近几天；“本周新认识”只统计升级之后才学的词（旧记录里没有“第一次学的日期”） |
| **小朋友账户** | 查看、切换、改名、删除小朋友；下载 / 导入记录文件；清空当前小朋友的进度（见下一节） |

## 小朋友账户、进度保存和换手机

**按名字分开**：第一次打开会问小朋友的名字，每个名字有自己的一份学习记录（进度、统计、打卡、设置都分开）。首页的“🧒 名字 ▾”可以切换小朋友或新增（最多 6 个），家长页的“小朋友账户”里可以切换、改名、删除。以前（没有名字时）玩出来的进度，会并入第一次输入的那个名字，不会丢。

**自动保存**：孩子每答一题就会保存到**这部手机的这个浏览器里**，下次打开接着玩，不用手动备份。但它**不会上传到网上**，所以下面这些情况记录会丢，**请先“下载记录”**：

- 换手机；
- 换一种打开方式（比如本来在微信里玩，改用 Safari/Chrome 打开，会是另一份新的记录）；
- 清理了浏览器或微信的缓存、卸载重装。

**下载记录：**家长页 → 小朋友账户 → 点某个小朋友的“下载记录”，得到一个 `abc_名字_日期.json` 文件（含逐题明细）。距离上次下载超过 14 天，页面会提醒。

**导入记录：**在新手机上打开同一个链接，第一次的“输入名字”页或家长页里点“导入记录文件”，选那个 json 文件。文件里带着名字：没有这个名字就新建；已经有同名的，会先问你是否覆盖。

**微信里下载不了文件？用“传送链接”。**微信内置浏览器不支持下载文件，所以在微信里打开时家长页会把“下载记录”换成“🔗 传送链接”：点一下，这个小朋友的进度会压进一条链接并自动复制（进度在网址 `#` 后面，不会发给任何服务器，约 0.5～3 KB）。把它发到另一边（文件传输助手、备忘录都行），在那边点开，或粘贴到手机浏览器的地址栏，会先显示“收到学习记录”确认页（写着名字、已学多少词；如果这边已有同名记录，会提醒会被覆盖），点“导入这份记录”才会真的导入。“输入名字”页里也有粘贴框，链接、“复制文字”、旧版备份文字都可以直接粘贴进去。链接和文字版都不含逐题明细（太长），所以换设备后“已记录作答”和每周小结里的正确率会从头算，其余进度、遗忘统计和曲线都在。需要完整明细时，用手机自带浏览器打开本页再“下载记录”。也可以用家长页“微信里下载不了文件？”那个文本框里的“复制文字 / 导入文字”。旧版“备份文字”也能导入（它没有名字，会覆盖当前小朋友的记录，覆盖前会确认）。

**微信和浏览器之间不会自动同步。**同一部手机上，微信内置浏览器和 Safari/Chrome 各有自己的存储，互相看不到；这个网站是纯静态的（没有服务器），所以做不到真正的自动同步。建议平时只用一个入口（总是微信，或者总是浏览器），需要换入口时用传送链接搬一次。

导入的内容会先检查：缺的字段补默认值，不合理的数值（比如等级 99）收回到合理范围，格式不对的整个拒绝，不会弄坏现有记录。

“**清空进度**”只清零当前这个小朋友的学习进度和统计，不能撤销；每天新词数和语速设置会保留。
## 常见问题

- **没声音**：打开手机媒体音量；iPhone 侧面的静音开关要关；先点一下页面再试。偶尔个别词没声音、或点了选项不进下一题，现在已经修过：语音加载失败会自动重试（先用后台预加载好的数据，再重新请求一次），等待都有超时，答对后最多等 8 秒就进下一题。如果还遇到，请记下是哪个词。语音文件本身可以用 `python tools/audit_audio.py` 检查（需要 ffmpeg）。
- **换了打开方式（微信 ↔ 浏览器）记录看不到了**：见上面“微信和浏览器之间不会自动同步”，用“传送链接”搬过去。
- **页面还是旧的 / 点了“今日魔法任务”没反应**：多半是浏览器缓存了旧文件。在链接后面加 `?v=数字` 再打开（比如 `…/abc_game/?v=9`），或清理缓存。进度不会因此丢失。
- **今天没有要复习的**：正常，会显示“自由练习”，用学过的词出题；当天新词达到上限时也是如此。
- **“跟读”没有星星**：微信内置浏览器通常不支持语音识别，会变成“录一段、回放，再和标准发音对比着听”。就算有星星，也只是“识别出来的词对不对得上”，不是真正的发音评分。

## 文件结构（改代码的人看）

纯静态网页，没有构建步骤，改完文件直接刷新就行。所有脚本都是普通 `<script>`，共用全局变量，加载顺序见 [index.html](index.html)（先内容，再语音，再核心，最后页面）。

```
abc_game/
├─ index.html            页面骨架：只放 HTML 和 <script> 引用
├─ css/style.css         全部样式
├─ js/
│  ├─ content/           内容（改词库、改图片在这里）
│  │  ├─ data.js           单元、单词、句子、夸奖语、动一动指令、故事
│  │  └─ art.js            简笔画（内联 SVG）
│  ├─ audio/             声音
│  │  ├─ play.js           播放：重试、超时、预加载、答对后的等待上限
│  │  └─ speak.js          音标显示、跟读打分、录音（单词/句子时长）
│  ├─ core/              不碰页面的核心逻辑
│  │  ├─ profile.js        小朋友账户（每人一份存档）
│  │  └─ srs.js            复习算法、存档清洗、设置、今日队列、每个词的记录
│  ├─ pages/             各个页面和流程
│  │  ├─ quest.js          今日魔法任务（新词页、选择题、说一说、动一动、完成页）
│  │  ├─ story.js          听故事，排顺序
│  │  ├─ garden.js         我的小花园
│  │  ├─ parent.js         家长页、遗忘曲线、各种设置滑块
│  │  └─ account.js        账户页、导入导出、传送链接、每周小结
│  └─ app.js             入口：首页、学一学、玩一玩，最后一行 boot()
├─ audio/                预先生成的 mp3：en en2 zh sen sen2 senzh act fx
├─ tools/                开发用的小工具（不会被网页加载）
│  ├─ gen_audio.py         从 data.js 用 edge-tts 生成 audio/ 里的 mp3
│  ├─ audit_audio.py       检查 mp3 是否损坏、是否静音（需要 ffmpeg）
│  └─ art_preview.html     一页看全部图片（本地起静态服务器后打开）
└─ tests/                自动检查
   ├─ run_all.ps1          一键运行下面全部：powershell -NoProfile -File tests\run_all.ps1
   ├─ test_play.js         播放层：竞态、超时、重试、预加载（node tests/test_play.js）
   ├─ test_speak.js        跟读、录音时长（node tests/test_speak.js）
   ├─ test_srs.js          复习算法、账户、导入导出、传送链接、设置（node tests/test_srs.js）
   ├─ art_check.html       图片是否都能画出来、彼此是否太像
   ├─ browser_test.html    在真实浏览器里把主要流程点一遍
   └─ run_page.ps1         用无头 Edge 运行上面两个 html
```

新增一个脚本时：放进对应文件夹，在 [index.html](index.html) 里按依赖顺序加一行 `<script>`，并把 `?v=` 数字加 1（手机会缓存脚本）；如果测试也要用它，在 `tests/test_srs.js` 里加载它。
