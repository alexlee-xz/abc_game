# ABC 英语小游戏

给 4–6 岁中国小朋友学英语单词的网页小游戏：看图、听声音、点一点，再配上“间隔复习”（按遗忘规律，在合适的时间让孩子再见到这个词），让单词记得更牢。纯静态网页，手机浏览器、微信里直接打开，不用安装。

在线地址：<https://alexlee-xz.github.io/abc_game/>

## 快速开始

1. 手机（微信或浏览器）打开上面的链接，**打开手机声音**。
2. 点首页的 **“今日魔法任务”**，陪孩子玩一组，几分钟就够。
3. 每天玩一次就好。
4. 偶尔点首页最下面的 **“家长页”**，看看孩子的进度。

建议把页面加到手机桌面或微信“收藏”，方便每天打开。

## 孩子怎么玩

首页有这几个入口：

- **今日魔法任务**：每天的主线。先认识几个新词，再“听一听，找一找”（听声音，从几张图里点对的那张）。到期该复习的旧词会自动混进来。做完后还可以点“再练一组”。
  - 词越熟，题越难：新词和刚学的词是 3 选 1、只听单词；长到 🌿 以后变成 4 选 1，干扰图会故意放容易混的（比如医生和护士）；长到 🪴 以后，“I can be a…”系列的词改成听整句找图。
  - 点错了不用着急：第一次点错会再读一遍；连点错 2 次，正确的图会亮起来并带着读。答错的词隔几题后会“再来一次”，这次只算练习。
  - 做完任务的页面会列出“家长小任务”：今天新学的词、答错过的词，附一句生活里怎么用（比如“看到消防车时说 Fire station!”）。
  - **英语为主，中文少说**：中文翻译只在“认识新朋友”页播；答题时只听英文，中文提示“听一听，找一找”只在每组前 2 题出现。想要以前那种每题都带中文的方式，家长页里可以改。
  - **换个人说**：复习题会随机用另一个英文声音（男声）读同一个词，让孩子认的是“这个词”而不是“这个声音”。新词一直用第一个声音。
  - **说一说**（偶尔出现）：挑一个已经很熟的词（🌳 以上），只给图、不播声音，让孩子用英语说出来，由家长点“说对了”或“没说出来”。说对算一次复习答对；没说出来不扣分，会带孩子读两遍，稍后补考一道选择题。
  - **动一动**（任务最后）：播一句英语指令，比如 “Show me a dancer!”“Slide down the pole!”，让孩子做动作，家长点“做完啦”。不计分。
- **听故事，排顺序**：学会一个单元的词后在首页解锁。先播一遍由几句话组成的小故事（比如“警报铃响了 → 我们到达大楼 → 火被扑熄了”），孩子把图片按故事的顺序一张一张点出来。点错会把整个故事再播一遍，不直接告诉答案。这一项不影响复习日程，家长页会记完成次数。
- **我的小花园**：每个词是一颗种子，答对越多越长大：🌰 → 🌱 → 🌿 → 🪴 → 🌳 → 🍎。头上有 💧 的小树“渴了”，表示该复习了。
- **单元练习**：按主题自由学。
  - 学一学：点图片听英文和中文；每个词下面有音标，点“跟读”让孩子读一读。
  - 玩一玩：听声音，找图片。

所有声音都是提前合成好的 mp3（英文用美式儿童感女声和美式男声，中文用普通话女声），微信里也能正常播放。

## 复习是怎么安排的

- 学会一个词后，会在第 **1、2、4、7、15、30** 天各再考一次，之后每 15 天一次。
- 新词当天要**连续 2 次“第一次就点对，而且不犹豫”**才算学会、小树才长大。猜对的、想了很久才点对的（听完题目后超过 9 秒），都不算学会。
- 点错了：小树降一级，明天再练。
- “再练一组”、不够题时补的“巩固题”，以及答错后的“再来一次”，都只是多练，不影响复习日程，也不影响统计。“动一动”和“听故事排顺序”也不影响。
- “说一说”说对了按复习答对算；没说出来不算遗忘，由稍后补考的那道选择题决定升级还是降级。
- 每组魔法任务至少 10 题。

## 家长页怎么看、怎么调

首页最下面点“家长页”，里面有：

| 栏目 | 看什么 / 能做什么 |
|---|---|
| 今天、学习进度、未来 7 天 | 今天任务做完没有、有几个词该复习、各成长阶段的词数、接下来几天要复习多少 |
| **今日家长小任务** | 今天新学的词和答错过的词，每个词附一句“在生活里怎么用”。孩子在现实中用一用，比多做几道题记得更牢 |
| 遗忘情况 | “隔天复习测试”做了几次，其中第一次就点错（遗忘）几次、占多少。**只有“以前学会过、隔了至少一天、第一次就点错”才算遗忘**，新词点错只算“还没学会”。测试不到 10 次时仅供参考 |
| **遗忘曲线** | 一张折线图：横轴是“隔了几天再测”，纵轴是“第一次就点对的比例”，点下面的 n 是测试次数。曲线掉得越慢，说明记得越牢。空心点表示测试少于 3 次，别当真；虚线是 80% 的参考线。要隔天复习的词多了才会有点，一开始是空的 |
| 最容易忘的词 / 还没学会的词 | 需要多陪孩子练的词 |
| **学习方式** | 三组开关：**中文翻译**（“只在新词页”默认，英语输入更多；“总是播放”适合刚接触英语的孩子）、**说一说**（开/关）、**动一动**（开/关）。孩子不愿意开口或者环境不方便时，可以先关掉说一说和动一动 |
| **每天新词数** | 滑块，1–20，默认 3。每个新词会先教一遍、当天再考 2 次。孩子觉得太简单就调大；注意力不够就调小 |
| **语速** | 两个滑块，范围 ×0.5–×2.0，默认 ×1.0（原速）。“提示语速”管中文提示和夸奖，“英语播放语速”管英文单词和句子，旁边有“试听”按钮。超出 ×0.7–×1.5 时声音可能有点变调；个别手机浏览器不支持变速，听着没变化时请改用系统浏览器打开 |
| 最近 30 天打卡 | 每天有没有完成魔法任务 |
| 备份 / 恢复 / 清空进度 | 见下一节 |

## 进度怎么保存？换手机怎么办？（备份与恢复）

**平时不用管**：孩子玩的进度会自动保存在**这部手机的这个浏览器里**，下次打开接着玩。

但它**不会上传到网上**，所以下面这些情况进度会丢，**请先备份**：

- 换手机；
- 换一种打开方式（比如本来在微信里玩，改用 Safari/Chrome 打开，会是另一份新的进度）；
- 清理了浏览器或微信的缓存、卸载重装；
- 两个孩子共用一部手机，会共用同一份进度。

**备份：**

1. 首页最下面点“家长页”，一直滑到最下面的“备份 / 恢复进度”；
2. 点“**复制**”，文本框里的一长串文字就复制好了；
3. 把它发给自己（比如微信“文件传输助手”、备忘录）保存。建议每隔一两周备份一次。

**恢复（换手机后）：**

1. 在新手机上打开同一个链接，进“家长页”；
2. 把保存的那串文字粘贴到最下面的文本框里（先清掉里面原有的内容）；
3. 点“**导入**”，提示“导入成功”就好了。

备份里有：每个词的学习进度、遗忘统计和遗忘曲线、打卡记录、每天新词数和语速设置。**不含**逐题的详细记录（太长，微信里发不出去），所以换手机后“已记录作答”会从 0 开始，但进度和曲线都在。

“**清空进度**”会把学习进度和统计全部清零，不能撤销；每天新词数和语速设置会保留。

## 常见问题

- **没声音**：打开手机媒体音量；iPhone 侧面的静音开关要关；先点一下页面再试。
- **页面还是旧的 / 点了“今日魔法任务”没反应**：多半是浏览器缓存了旧文件。在链接后面加 `?v=数字` 再打开（比如 `…/abc_game/?v=9`），或清理缓存。进度不会因此丢失。
- **今天没有要复习的**：正常，会显示“自由练习”，用学过的词出题；当天新词达到上限时也是如此。
- **“跟读”没有星星**：微信内置浏览器通常不支持语音识别，会变成“录一段、回放，再和标准发音对比着听”。就算有星星，也只是“识别出来的词对不对得上”，不是真正的发音评分。
